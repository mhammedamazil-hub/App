one-time step must be done by a human account — it takes about a minute.

On the page that opens, just click **"Commit changes…"** → **"Commit directly to the arena/01a008ff-app branch"** → **Commit changes**.

## The manual way (if the link misbehaves)

1. Open your repo → **Add file** → **Create new file**.
2. Name it exactly: `.github/workflows/build-apk.yml`
3. Copy the whole content of
   [`tool/build-apk-workflow.yml`](https://github.com/mhammedamazil-hub/App/blob/arena/01a008ff-app/tool/build-apk-workflow.yml)
   and paste it into the editor.
4. Choose **"Commit directly to the arena/01a008ff-app branch"** → **Commit changes**.

## What happens next

The moment the file is committed, GitHub Actions starts a build
(≈8–12 minutes): it runs the unit tests, builds the APKs and publishes them
to a **Release**. You'll find the download page at:

**https://github.com/mhammedamazil-hub/App/releases/latest**

Each new push to the branch refreshes that release automatically.
